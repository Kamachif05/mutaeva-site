# Сайт Карины Мутаевой

Обновлённая публичная страница и защищённое управление ценами для Москвы и Махачкалы.

35 услуг и 70 исходных цен перенесены из исходной версии сайта. Каталог, портрет и контактные ссылки сохранены. На главной странице доступны выбор города и поиск услуги. Страница `/admin/` позволяет редактировать суммы и признак «от».

## Проверка и запуск

Нужен Node.js 22 или новее. Сторонних зависимостей у приложения нет.

```text
npm run build
npm test
npm run setup-admin
```

`setup-admin` принимает пароль скрытым вводом, сохраняет только его отпечаток в `runtime/admin.json` и не перезаписывает существующую учётную запись. Каталог `runtime`, папка `secrets` и `.env` исключены из Git.

Скопировать `.env.example` в `.env`, указать действительные адреса и запустить `npm start`. Для локального просмотра задать `LOCAL_DEVELOPMENT=true`, удалить `NODE_ENV=production` и использовать `ADMIN_ORIGIN=http://127.0.0.1:3000`. В рабочей среде обязателен HTTPS.

## Работа с ценами

Войти, найти услугу, изменить цену в нужном городе, при необходимости отметить «Стоимость от», нажать «Сохранить цены». Сайт получает значения от сервиса при открытии страницы. Подтверждение сохранения включает повторное чтение с сервера.

Допустимы целые суммы 0-1 000 000 рублей. Значение 0 отображается как 0 ₽. Каталог услуг фиксирован; добавление и удаление услуг не входит в этот выпуск. При изменениях из другой вкладки сохранение останавливается, текущий ввод остаётся в форме. Кнопка «Загрузить сохранённые цены» заменяет ввод после подтверждения.

Если сервис цен недоступен, публичная страница сообщает об этом и предлагает повторить загрузку или уточнить стоимость при записи. Старые цены при ошибке не выдаются за текущие.

## Хранение и защита

`data/seed.json` содержит исходные цены для первого запуска. После запуска источником является `prices.json` в каталоге `DATA_DIRECTORY`. Сервер пишет изменения атомарно и сохраняет предыдущую версию в `backups`. Повреждённый файл приводит к остановке запуска; автоматического сброса цен нет.

Сессия длится четыре часа. Cookie защищена HttpOnly, Secure и SameSite=Strict. Запись требует сессии, разрешённого Origin и CSRF-токена. Вход ограничен десятью попытками за пятнадцать минут на адрес, до четырёх одновременно. За обратным прокси этот лимит общий для подключений прокси: сервис намеренно не доверяет произвольному `X-Forwarded-For`. Перезапуск завершает активные сессии. Пароль не хранится в открытом виде на сервере.

Веб-сервер отдаёт только разрешённые публичные файлы. Исходники сервера, настройки, учётные данные и хранилище недоступны через HTTP.
